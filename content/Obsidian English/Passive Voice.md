# Passive Voice

Source: [[Sources and Reading Notes#S2 - Open source|S2]], pp. 1-3; chart on pp. 2-3.

Use the passive when you want to focus on the **receiver of an action**, or when the person doing it is unknown or unimportant.

**Pattern:** `receiver + appropriate form of be + past participle (+ by + doer)`

Source example: “Projects will be built in public.”

## Active → passive

New example:

- Active: **The team reviews the code.**
- Passive: **The code is reviewed by the team.**

1. Make the active object (*the code*) the passive subject.
2. Put **be** in the appropriate tense and number.
3. Use the main verb's **past participle** (*reviewed*).
4. Add **by the team** only if the doer matters.

## Forms used in the lesson

All examples below are new.

| Meaning or tense | Passive structure | Example |
| --- | --- | --- |
| Present simple | am/is/are + participle | The code **is reviewed** daily. |
| Past simple | was/were + participle | The bug **was fixed** yesterday. |
| Present perfect | has/have been + participle | The tests **have been added**. |
| Present continuous | am/is/are being + participle | The issue **is being discussed**. |
| Going-to future | am/is/are going to be + participle | The design **is going to be changed**. |
| Will future | will be + participle | The patch **will be released** tomorrow. |
| Modal passive | can/must/should/might + be + participle | The code **can be audited**. |

**Be carries the tense; the past participle stays the same.** Irregular examples: *build → built*, *write → written*, *hide → hidden*.

## Negatives and questions

New examples:

- The bug **wasn't fixed**.
- The feature **hasn't been released** yet.
- The code **must not be merged** yet.
- **Was** the bug **fixed**?
- **Has** the code **been reviewed**?
- **Can** the issue **be reproduced**?

Move the first auxiliary before the subject to form the question. See [[Rhetorical Questions]] for another use of question forms.

## Keep the meaning precise

*Not every issue has been solved* means **at least one issue remains unsolved**; it does not mean that no issues have been solved.

Only verbs that take a suitable object normally form this kind of passive. *A problem came up* does not become *A problem was come up*.

## Common mistakes

| Incorrect | Correct | Reason |
| --- | --- | --- |
| The code is review. | The code is reviewed. | Use the participle. |
| The patch will released. | The patch will be released. | Keep **be**. |
| The tests has been added. | The tests have been added. | Agree with plural **tests**. |
| The issue is been discussed. | The issue is being discussed. | Continuous passive uses **being**. |

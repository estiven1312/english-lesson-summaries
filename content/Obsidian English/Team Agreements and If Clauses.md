# Team Agreements and If Clauses

Source: [[Sources and Reading Notes#S1 - Getting along|S1]], p. 1. The lesson's main grammar target is [[Phrasal Verbs]]; these if-clause patterns are an additional study connection from its article.

Use **if + present simple, imperative** to state what someone should do when a situation occurs.

Source example: “If you can't finish a task, hand it off before the sprint ends.”

## Team-rule pattern

`if + present condition, instruction`

New examples:

- **If you join late, mute your microphone.**
- **If an issue comes up, go over it together.**
- **If a ticket is finished, close it out.**

An imperative normally has no written subject; the understood subject is **you**. Use **don't + base verb** for a negative instruction:

**If you disagree, don't put off the conversation.**

When the if-clause comes first, separate it with a comma. When it comes second, a comma is usually unnecessary:

**Hand it off if you can't finish it.**

## Rule versus future consequence - study extension

| Purpose | Pattern | New example |
| --- | --- | --- |
| Team instruction | if + present, imperative | If the build fails, check the logs. |
| General relationship | if + present, present | If notifications interrupt me, I lose focus. |
| Possible future result | if + present, will + base | If the build fails, we'll delay the release. |

For an ordinary future condition, use present tense after *if*: **If it fails**, not *If it will fail*.

## Before, when, as soon as

The article also uses time clauses to organize team actions.

New examples:

- Close the ticket **as soon as you finish**.
- Hand off the task **before the sprint ends**.
- Ask for help **when a problem comes up**.

For future time in these clauses, normally use present simple: **before the sprint ends**, not *before the sprint will end*.

## Six original team agreements

1. If a blocker **comes up**, tell the team.
2. If you cannot finish a task, **hand it off** with context.
3. **Go over** the acceptance criteria before coding.
4. **Turn off** unnecessary notifications during focus time.
5. Don't **put off** difficult feedback.
6. **Close out** tickets as soon as the work is complete.

Related: [[Verb Complements and Cause and Result]] explains *Turn off notifications to prevent interruptions from breaking your focus*. [[Modal Verbs]] helps soften instructions: **You might want to mute notifications.**

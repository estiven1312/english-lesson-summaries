# Grammar Connections

The same sentence can combine several topics from different PDFs. These are original examples built from the lesson patterns.

## One workplace situation, several choices

| What you want to say | Sentence | Grammar link |
| --- | --- | --- |
| Describe a problem | A blocker **came up** yesterday. | [[Phrasal Verbs]] |
| State a team response | **If** a blocker comes up, **hand it off** with context. | [[Team Agreements and If Clauses]] |
| Ask politely | **Could** you **go over** the logs? | [[Modal Verbs]] + [[Phrasal Verbs]] |
| Focus on the action | The logs **should be reviewed**. | [[Modal Verbs]] + [[Passive Voice]] |
| Explain a benefit | Reviewing the logs **helps us identify** the cause. | [[Verb Complements and Cause and Result]] |
| Explain prevention | Tests **prevent regressions from reaching** production. | [[Verb Complements and Cause and Result]] |
| Report a claim | Pair review **is thought to improve** quality. | [[Reporting Passive]] |
| Express skepticism | **Can** one review **really catch** every bug? | [[Rhetorical Questions]] |
| Describe time pressure | We're **working against the clock**. | [[Idioms and Fixed Expressions]] |

## Base verb, to-infinitive, or -ing?

- We **should review** it. → modal + base verb
- We **want to review** it. → want + to-infinitive
- We **look forward to reviewing** it. → preposition + -ing
- The checklist **helps us review** it. → help + object + base verb
- The checklist **enables us to review** it. → enable + object + to-infinitive
- The checklist **prevents us from missing** a step. → prevent + object + from + -ing

See [[Gerunds and Infinitives]] for the shared principle: learn the governing word together with the pattern it requires.

## A longer example

**Async updates are believed to help developers avoid putting off difficult conversations.**

| Chunk | Job |
| --- | --- |
| Async updates | subject |
| are believed to | reporting passive |
| help developers avoid | help + object + base verb |
| avoid putting off | avoid + -ing |
| putting off difficult conversations | phrasal verb meaning delaying conversations |

This is an example of grammar, not evidence that async updates have this effect.

## Similar forms, different purposes

- **Can everyone see the screen?** normally checks ability and invites a response.
- **Can any tool really catch every bug?** may make a skeptical rhetorical point.
- **The code must be reviewed.** expresses an obligation.
- **The reviewer must be busy.** expresses a deduction.
- **The code is being reviewed.** describes an action happening now.
- **The code has been reviewed.** describes a completed review relevant now.

# Phrasal Verbs

Source: [[Sources and Reading Notes#S1 - Getting along|S1]], pp. 1-3; grammar chart on p. 2.

A multiword verb combines a verb with a particle or preposition. Learn its meaning **and its object position**. The lesson uses *phrasal verbs* as a broad label for these expressions.

## 1. No object

**Pattern:** `subject + verb + particle`

Source example: “When a problem comes up, go over things right away.”

In *a problem comes up*, nothing follows *comes up* as its object. It means a problem appears.

New examples:

- Please **come in** quietly.
- A new issue **came up** yesterday.
- I hope everything **works out**. (= ends well)

The base verb changes tense: *come up → came up → has come up*.

## 2. Separable verbs with an object

With a noun, two positions are often possible:

- **Turn off the notifications.**
- **Turn the notifications off.**

With a personal pronoun, put the pronoun **between** the verb and particle:

- **Turn them off.**
- Incorrect: *Turn off them.*

| Expression | Meaning in this lesson | New example with a pronoun |
| --- | --- | --- |
| close out a ticket | finish and formally close it | Close it out. |
| hand off a task | transfer responsibility | Hand it off to Ana. |
| put off a conversation | delay it | Don't put it off. |
| pick up a task | take it on | Can you pick it up? |
| give up a habit | stop the habit | I'm trying to give it up. |
| figure out a solution | understand or find it | We figured it out. |

*Give up* also occurs without an object: “Don't give up!”

## 3. Fixed object position

Put the object **after the whole expression**:

| Expression | Meaning | New example |
| --- | --- | --- |
| get over something | recover from it | We got over the problem. |
| go over something | review or discuss it | Let's go over it. |
| put up with something | tolerate it | I can't put up with the noise. |
| run out of something | have none left | We've run out of time. |
| come up with something | produce an idea or solution | She came up with a plan. |
| look forward to something | feel pleased about a future event | I'm looking forward to the workshop. |

Incorrect: *Let's go it over.* Correct: **Let's go over it.**

## 4. When the next action uses -ing

- **look forward to joining** the team
- **put off giving** feedback
- **give up checking** messages at night
- **put up with waiting** for reviews

In *look forward to*, **to is a preposition**, so use a noun or an -ing form. Compare *I want to join*: here *to* introduces an infinitive. See [[Gerunds and Infinitives]].

## Clarification of the source chart

The chart lists *go over* among verbs with no object, but its own example, *go over things*, has an object. For the meaning **review/discuss**, learn **go over + object**, with fixed order. *Work out* also has different patterns: *Things worked out* (no object) versus *We worked it out* (solved it).

## Try it

Replace *the task* with *it*: “Please hand the task off to Luis.”

Answer: **Please hand it off to Luis.**

# Presenting a Project Update

Source: [[Sources and Reading Notes#S3 - Presenting a project update|S3]], p. 1, sections 1 and 2.

A project update works well when listeners know what you are discussing, what has changed, what is uncertain, and what you need next.

## Reusable language

Short frames from the source, with new completions:

| Function | Frame and example |
| --- | --- |
| Start | **Let's get started.** |
| Introduce the topic | **I want to look at** the latest release. |
| Preview the content | **I'll be talking about** progress and blockers. |
| Explain the first step | **I'd like to begin by** showing the test results. |
| Check visibility | **Can you all see** the diagram? |
| Refer to evidence | **As you can see**, the error rate has fallen. |
| Move to another point | **Let's move on and look at** the remaining issue. |
| End | **I'd better stop there.** |
| Invite discussion | **Does anyone have any questions or comments?** |
| Hand over | **I'll turn it over to** Ana. |

## Grammar inside the frames

- **Let's + base verb**: *Let's begin*, not *Let's to begin*.
- **Would like + to-infinitive**: *I'd like to explain*.
- **By + -ing**: *begin by showing*, not *begin by show*.
- **Will be + -ing**: *I'll be talking* previews an activity during the presentation.
- **Had better + base verb**: *I'd better stop*. Here **'d means had**.
- **Turn it over to someone**: *it* goes between the verb and particle. See [[Phrasal Verbs]].

## Tenses for an update - study extension

Examples are new.

| What you communicate | Useful form | Example |
| --- | --- | --- |
| Work in progress now | present continuous | We're testing the login flow. |
| A completed change relevant now | present perfect | We've added validation tests. |
| A finished event at a finished past time | past simple | We found the bug yesterday. |
| A current state | present simple | The fix works in staging. |
| A planned next step | going to | We're going to retest tomorrow. |
| An expected result | should + base verb | The patch should be ready today. |

Avoid *We've found it yesterday*. Use **We found it yesterday** because *yesterday* identifies a finished past time.

## Original model update

> Let's get started. I'd like to begin by showing the login changes. We've added validation tests, and we're checking the refresh-token flow. The issue might be related to session expiry. The fix should be ready tomorrow, but it must be reviewed before release. Could someone go over the logs with me? That's all I have time for. Does anyone have any questions? I'll turn it over to Ana.

Notice the connections:

- **might be** = possibility; **should be** = expectation → [[Modal Verbs]]
- **must be reviewed** = modal + passive → [[Passive Voice]]
- **by showing** = preposition + -ing → [[Gerunds and Infinitives]]
- **go over the logs** = review them → [[Phrasal Verbs]]

Practise replacing the project details with your own. Keep the uncertainty level accurate: *might* and *must* express different degrees of confidence.

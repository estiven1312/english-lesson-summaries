## A. Match presentation functions - PDF section 1C

Match each function with an expression group.

1. Start the presentation.
2. Introduce the topic.
3. Check that everyone can see or hear.
4. Refer to a slide, a handout, or questions.
5. Go to a new topic or person.
6. End the presentation.

A. As you'll see on the slide... / Does anyone have any questions or comments?
B. Let's get started.
C. Let's move on and look at... / I'll turn it over to Camila.
D. Anyway, that's all I have time for. / I'd better stop there. / I'll just conclude by saying thank you for listening.
E. I want to look at... / I'll be talking about... / I'd like to begin by...

## C. Choose the best modal - PDF section 2B

Each pair reproduces the PDF choices. Several forms are grammatically possible in isolation; choose the one that best fits the surrounding situation.

### Situation 1 - getting ready

1. ______ everyone see the screen? **(Can / Would)**
2. You ______ all have the project brief by now. **(could / should)**
3. Oh wait - the staging build ______ load. **(might not / won't)**
4. It ______ be down. **(might / ought to)**
5. ______ someone check the status page for me please? **(May / Could)**
6. Thanks. OK. So ______ you see the screen clearly now? **(would / can)**

### Situation 2 - explaining a blocker

1. You ______ be wondering why the refresh-token issue only happens after a long session. **(need to / must)**
2. It ______ be useful to show you the logs. **(might / had better)**
3. First, I ______ open the latest run. **(need to / would)**
4. Um, that ______ be the failed request. **(must / can)**
5. Oh, ______ check the previous token refresh too. **(I'd better / I won't)**
6. That's better. You ______ be able to see the error here. **(would / ought to)**

### Situation 3 - handing over

1. Camila, ______ I ask you to share your screen, please? **(may / would)**
2. Thanks. You ______ open the latest build first. **(might want to / would)**
3. And ______ you show everyone the new error state? **(should / would)**
4. Great. Well, that's all I have time for. I ______ stop now. **(won't / have to)**

## D. Give an update - PDF section 2C

Choose a current or recent project and cover:

- what you're working on;
- what's working;
- a blocker or uncertainty;
- what needs to happen next;
- something you need from the team;
- a clear ending.

Use at least six presentation expressions from A and modal verbs where they fit naturally. Write your response here: ______

## Answers

### A

**1-B, 2-E, 3-F, 4-A, 5-C, 6-D.**

### B

1. **There should be a project brief in the chat.**
2. **The staging build won't load.**
3. **Would somebody open the ticket, please?**

These follow the actual presentation. *Ought to* is an alternative for the expectation in B1; *Could somebody...* is another polite request for B3.

### C - best contextual choices

| Item | Answer | Meaning |
| --- | --- | --- |
| 1.1 | Can | ability/checking visibility |
| 1.2 | should | expectation |
| 1.3 | won't | observed failure to load |
| 1.4 | might | possible explanation |
| 1.5 | Could | polite request |
| 1.6 | can | ability after the adjustment |
| 2.1 | must | strong assumption about the audience |
| 2.2 | might | tentative suggestion |
| 2.3 | need to | necessary next action |
| 2.4 | must | deduction from the evidence |
| 2.5 | I'd better | advisable immediate action |
| 2.6 | ought to | expected ability |
| 3.1 | may | formal permission to make a request |
| 3.2 | might want to | soft suggestion |
| 3.3 | would | request |
| 3.4 | have to | necessity/time limit |

In 1.3, *might not load* could express a prediction about a possible failure; *won't load* best matches the speaker noticing that the build is failing now. In 2.3, *would open* could fit a hypothetical context, which the visible dialogue does not supply. The choices above follow the most natural reading of the screenshot.

### D - original sample answer

Let's get started. I want to look at the login update. I'll be talking about progress and the remaining blocker. I'd like to begin by showing the new tests. As you can see, the validation works, but the session issue might be related to token expiry. We should have a fix tomorrow. Could someone review the logs with me? Let's move on and look at the next steps. Anyway, that's all I have time for. Does anyone have any questions or comments? I'll turn it over to Camila.

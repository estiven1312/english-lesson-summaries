## A. Choose the topic - PDF section 2

The source asks you to listen. For this Markdown version, use the **written interview on p. 1** instead. Which sentence best illustrates the topic?

A. A developer working alone on a private codebase.
B. A distributed team contributing to a shared repository.
C. A corporation buying a software license.
D. A single company maintaining a product in secret.

## B. Rewrite in the passive - PDF section 4

Start with the words in parentheses.

1. A group of engineers and activists developed the idea in the late 1990s. **(The idea...)**
2. Developers will build projects in public. **(Projects...)**
3. A single company won't hide bugs. **(Bugs...)**

## C. Complete the passive forms - PDF section 5

Use these active statements to complete the sentences below:

- Teams use open source software. Developers will build projects in public.
- Open source communities haven't solved every sustainability issue yet. Conference organizers are going to discuss the future of open source this week.
- A single company won't hide bugs. Anyone can audit the code at any time.

1. Open source software ______ by teams. Projects ______ in public.
2. Not every sustainability issue ______ yet. The future of open source ______ at the conference.
3. Bugs ______ by a single company. The code ______ by anyone at any time.

## D. Choose the correct alternative - added practice

1. The code ______ by anyone. A) can audit B) can be audited C) can be audit
2. The idea ______ in the 1990s. A) was developed B) is develop C) has develop
3. The issue ______ this week. A) is going discuss B) is going to be discussed C) going to discussed
4. Not every issue has been solved means: A) no issues have been solved B) at least one issue remains unsolved C) all issues have been solved

## E. Discuss - PDF group task

Write two advantages and one disadvantage of open source software. Use the passive when the result matters more than the person doing the action. Treat your sentences as discussion points, not universal claims.

- Advantage 1: ______
- Advantage 2: ______
- Disadvantage: ______

## Answers

### A

**B.** The written interview concerns public development and community contributions.

### B

1. **The idea was developed by a group of engineers and activists in the late 1990s.**
2. **Projects will be built in public.**
3. **Bugs won't be hidden by a single company.**

### C

1. **is used; will be built**
2. **has been solved; is going to be discussed**
3. **won't be hidden; can be audited**

*Not every issue has been solved* preserves the meaning that some issues remain unsolved. It does not assert that none have been solved.

### D

1. **B** - modal + be + past participle.
2. **A** - past simple passive for a finished past time.
3. **B** - going to + be + past participle.
4. **B** - at least one issue remains unsolved.

### E - sample response

The code **can be inspected** by independent developers. Fixes **can be contributed** by people outside the original team. However, important maintenance tasks **may be delayed** if there are too few maintainers.

Other well-formed, relevant responses are valid. Review [[Passive Voice]] and [[Modal Verbs]].

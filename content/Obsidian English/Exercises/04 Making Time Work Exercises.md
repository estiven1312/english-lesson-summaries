These items adapt the article wording into new blanks. They are not missing rows recovered from the cut-off chart.

## Answers

### A - possible summaries

| Strategy | What it prevents or protects | Benefit |
| --- | --- | --- |
| meeting-free mornings | protects deep work sessions from meeting overload | gives engineers thinking time before lunch |
| task priority system | prevents decision fatigue from slowing you down | helps you choose what to work on next |
| async communication | protects time from being lost to long message threads | reduces unnecessary communication overhead |
| end-of-day shutdown ritual | keeps work anxiety from following you into personal time | helps separate work and personal time |
| focused sprints | short breaks reduce the draining effect of long sessions | lets the brain recover between tasks |
| weekly plan | helps prevent taking on too much work and last-minute stress | supports a realistic workload |
| calendar buffer | protects processing time between calls | gives you time to process the previous meeting |

The article does not explicitly state a separate prevention effect for every strategy. Some cells above paraphrase the described benefit. Equivalent summaries are valid. Preserve the article's tentative wording when discussing the claims: *may*, *can*, *is thought to*.

### B

1. **do** - help + object + base verb; *help you to do* is also possible in general.
2. **to disappear** - cause + object + to-infinitive.
3. **from following** - keep + object + from + -ing.

### C

1. **to do**
2. **decide / to decide** - both are grammatical after *help*.
3. **slowing**
4. **losing**
5. **recover**
6. **taking**
7. **going**
8. **feel**

### D

1. **A** - help me focus. *Help me to focus* is also valid, but is not among these choices.
2. **A** - let + object + base verb.
3. **B** - cause + object + to-infinitive.
4. **C** - prevent + object + from + -ing.
5. **A** - reporting passive + to-infinitive.

# Grammar Practice

These exercises and answers are original study material, not an official answer key to the PDFs. Follow the topic links if you want to review a pattern.

## A. Choose the form

1. I'm looking forward to ___ the team. (join / joining)
2. The manager let us ___ early. (leave / to leave)
3. Quiet time enables me ___ deeply. (focus / to focus)
4. The plan prevents us from ___ too much work. (accept / accepting)
5. You should ___ the logs. (check / to check)
6. We'd better ___ now. (stop / to stop)
7. The tool is believed ___ time. (save / to save)
8. I'd like to begin by ___ the results. (show / showing)

## B. Rewrite

9. Replace *the notifications* with *them*: “Turn off the notifications.”
10. Replace *the proposal* with *it*: “Let's go over the proposal.”
11. Make passive: “The team fixed the bug yesterday.”
12. Make passive: “Someone must review the code.”
13. Make passive: “They have added two tests.”
14. Rewrite using *is said to*: “People say that time blocking improves focus.”
15. Join as a team instruction: “A blocker comes up. Tell the team.”

## C. Meaning

16. “The server must be down.” Is this an obligation or a deduction?
17. “You don't have to join.” Does this mean joining is prohibited or optional?
18. “Can any tool really catch every bug?” What point might the speaker be making?
19. “The build won't load.” What does *won't* mean here?
20. “Not every issue has been solved.” Does this necessarily mean no issue has been solved?

## D. Correct the mistake

21. Does she believes the result?
22. We must to check it.
23. This prevents me from lose focus.
24. The patch will released tomorrow.
25. If the build will fail, check the logs.
26. We've found the bug yesterday.
27. She has found his feet in the new team. (Use the pronoun that refers to *she*.)

## Answers and explanations

> [!tip] Try first
> Answer before reading this section. Some rewrites have more than one valid wording.

1. **joining** - *look forward to* ends in a preposition. [[Gerunds and Infinitives]]
2. **leave** - active *let + object + base verb*. [[Verb Complements and Cause and Result]]
3. **to focus** - *enable + object + to-infinitive*.
4. **accepting** - *from + -ing*.
5. **check** - core modal + base verb. [[Modal Verbs]]
6. **stop** - *had better + base verb*.
7. **to save** - reporting passive + to-infinitive. [[Reporting Passive]]
8. **showing** - *by + -ing*.
9. **Turn them off.** The pronoun goes between the verb and particle. [[Phrasal Verbs]]
10. **Let's go over it.** *Go over* meaning review has fixed object position.
11. **The bug was fixed by the team yesterday.** Past simple passive. [[Passive Voice]]
12. **The code must be reviewed.** Modal + be + participle.
13. **Two tests have been added.** Present perfect passive; plural subject takes *have*.
14. **Time blocking is said to improve focus.**
15. **If a blocker comes up, tell the team.** [[Team Agreements and If Clauses]]
16. **Deduction** - the speaker strongly concludes that it is down.
17. **Optional** - *don't have to* means there is no obligation.
18. **Probably no tool can catch every bug.** This reading depends on context. [[Rhetorical Questions]]
19. **Failure to operate** - it is not loading.
20. **No.** It means at least one issue remains unsolved; others may have been solved.
21. **Does she believe the result?** Use the base verb after *does*.
22. **We must check it.** No *to* after *must*.
23. **This prevents me from losing focus.**
24. **The patch will be released tomorrow.**
25. **If the build fails, check the logs.** Present simple in the condition.
26. **We found the bug yesterday.** Finished past time takes past simple here.
27. **She has found her feet in the new team.** Change the possessive with the person. [[Idioms and Fixed Expressions]]

## E. Create your own example

Give a one-minute update with:

- one completed change;
- one current task;
- one possibility with *might*;
- one expected result with *should*;
- one passive sentence;
- one polite request with a phrasal verb.

Use [[Presenting a Project Update]] as a model. Then explain a work habit using *helps me do*, *enables me to do*, and *prevents me from doing*.

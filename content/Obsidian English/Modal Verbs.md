# Modal Verbs

Source: [[Sources and Reading Notes#S3 - Presenting a project update|S3]], p. 1, section 2.

Modals express how a speaker views an action: possible, expected, necessary, permitted, or advisable. Their meaning depends on context.

## Basic structure

`subject + modal + base verb`

New examples: **She can help.** **They might join.** **We should wait.**

Do not add third-person **-s**, **do**, or **to** after a core modal:

- Incorrect: *She cans help.* → **She can help.**
- Incorrect: *Do you can see it?* → **Can you see it?**
- Incorrect: *We must to stop.* → **We must stop.**

Forms such as **have to**, **need to**, **ought to**, and **had better** are related expressions with their own patterns.

## Meanings in project updates

Examples in this table are new.

| Purpose | Form | Example and meaning |
| --- | --- | --- |
| Expectation | should / ought to | The fix **should arrive** today. I expect it. |
| Strong deduction | must | The server **must be** down. The evidence strongly suggests this. |
| Possibility | might / may / could | The error **might be** in the cache. It is one possibility. |
| Obligation | must / have to / need to | We **have to finish** the review today. |
| Advice | should / ought to | You **should add** a test. |
| Soft suggestion | might want to | You **might want to check** the logs. |
| Urgent advice | had better | We'd **better stop** now or we'll miss the next meeting. |
| Ability | can | **Can** everyone **read** the text? |
| Failure to operate | won't | The application **won't start**. It is failing to start. |
| Request | can / could / would | **Could** you **open** the ticket, please? |
| Offer | will / can / could | I **can share** my screen. |
| Permission | can / could / may | **May I ask** a question? |

Source example: “The staging build must be refreshing.” Here **must** expresses a deduction, and **be refreshing** describes a process happening now.

## Useful distinctions

**Should** can express either advice or expectation:

- **You should review it.** = My advice is to review it.
- **It should be ready.** = I expect that it is ready.

**Must** can express either obligation or deduction:

- **You must check it.** = Checking is required.
- **It must be broken.** = I strongly conclude that it is broken.

**Won't** can describe refusal or failure to work. A program that *won't load* is not literally making a decision.

## Related expressions

- **have to + base verb**: *She has to leave.* / *Does she have to leave?*
- **need to + base verb**: *We need to test it.*
- **ought to + base verb**: *We ought to test it.*
- **had better + base verb**: *I'd better leave.* Here **'d = had**.
- **would like to + base verb**: *I'd like to begin.* Here **'d = would**.

The source groups *should*, *ought to*, *have to*, *need to*, and *had better* under necessity. They differ in force: advice is weaker than an obligation, and *had better* often implies an undesirable consequence.

## Negative meanings - study extension

- **mustn't** = prohibited: *You mustn't share the password.*
- **don't have to / don't need to** = optional: *You don't have to attend.*
- **shouldn't** = inadvisable: *You shouldn't skip the tests.*

For permission, **could I...?** is a polite question; a direct granting response is normally **Yes, you can/may**.
